# Antenne accordée 868 MHz 4.4 dBi pour LoRa / ISM868 / Meshtastic / Helium / Sigfox
**Référence : OPA-ANT-FIXE-868-V2-N-1568**

---

## 📡 Caractéristiques principales
- **Fréquence** : 868 à 870 MHz
- **Bande compatible** : LoRa (LoRaWAN), Sigfox, Helium, Meshtastic, Zigbee
- **Gain** : **4.4 dBi** (2.25 dB)
- **SWR** : ≤ 1.2
- **Impédance** : 50 Ohms
- **Puissance maximale** : 10W (40 dBm)

---

## 🧱 Construction
- **Type d'antenne** : Colinéaire à **2 éléments couplés**
- **Polarisation** : Verticale
- **Radôme** : Fibre de verre résistante aux UV
- **Couleur** : Blanc
- **Connecteur** : N femelle

---

## 📏 Dimensions
- **Longueur totale** : 52,5 cm
- **Diamètre du radôme** : 26 mm
- **Diamètre du tube à la base** : 32 mm

---

## ⚙️ Installation
- **Montage sur mât** : 35 à 70 mm de diamètre
- **Fixation** : Étrier fourni
